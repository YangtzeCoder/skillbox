# 改之前先确认

当本技能触发时，先输出 Markdown 修改稿。

## 规则

- 确认前可以读取、分析目标，以及创建确认稿目录、保存确认稿和记录目录偏好；不得修改、删除或覆盖目标内容。
- 确认稿逐项列出原来的内容与准备修改后的内容；新增内容注明“新增”，删除内容注明“准备删除”，并注明“目标尚未修改”。
- 展示确认稿后，通过提问工具询问用户是否确认执行，提供“确认执行”和“继续调整”选项。
- 用户提出调整时，先更新确认稿，再通过提问工具重新询问。
- 仅当用户单独回复“确认执行”，或在提问工具中选择“确认执行”时，才按当前确认稿执行修改。

## 确认稿目录

- 用户已指定保存目录时，使用用户指定的目录。
- 否则，遵循适用的 AGENTS.md 中关于确认稿目录的明确规定。
- 没有明确规定时，询问用户保存目录，默认选项为项目根目录下的 prepare/。
- 用户选择或接受默认目录后，将该约定记录到项目根目录的 AGENTS.md；文件不存在时创建。
- 记录时仅新增或更新确认稿目录约定，保留其他内容，避免重复记录。
- 目录确定后，创建必要的目录并保存 Markdown 确认稿。
- 后续任务读取该约定，不再重复询问；用户要求更换目录时同步更新。
